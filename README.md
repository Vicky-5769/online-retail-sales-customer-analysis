# Online Retail Sales & Customer Behavior Analysis

## Project Overview

This project analyzes online retail transaction data to understand sales performance and customer purchasing behavior.

The project includes data cleaning, exploratory data analysis, RFM analysis, customer segmentation using K-Means clustering, SQL analysis, and machine learning to predict whether a customer will make a future purchase.

## Objectives

- Analyze retail sales and revenue trends
- Identify top-performing products and countries
- Understand customer purchasing behavior
- Segment customers based on RFM analysis
- Predict future customer purchases using Machine Learning
- Generate business insights from the analysis
